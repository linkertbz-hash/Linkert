# Public portfolio security policy

- Source code for AVEXIUM, Finansteh and Parser stays in private repositories.
- Never copy commercial source, deployment files, secret values, API credentials, internal dashboards, customer data or database exports into public portfolio repos.
- Publish only high-level product descriptions and public-domain URLs.
- Do not present Parser as written in Python; use a fully independent study project to demonstrate Python skills.
- A review branch is not a new GitHub profile repository.
- Never change repository visibility or modify deployment branches as part of portfolio publishing.
